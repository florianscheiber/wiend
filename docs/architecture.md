# Architecture

- Package name: `wiend`
- License: MIT
- Distribution: PyPI
- Data distribution: GitHub Release Assets
- Local cache directory: `~/.wiend/`
- Supported outputs: `xarray.Dataset` and Zarr
- Geographic scope: Europe only
- Public API:
  - `download()`
  - `downscale()`
  - `download_and_downscale()`
- Minimum Python version: 3.11
